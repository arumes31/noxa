# B3 workspace

Approved direction: B3, the compact desktop console with live participant strip.

The desktop keeps a horizontal application menu and server tabs, a nested channel/member tree, a conversation area with Chat and Files views, and a contextual member inspector. A compact strip reflects the current voice channel's participants and speaking state. Voice actions stay in a bottom toolbar across both views. Member details provide local volume and messaging, with identity and server diagnostics in disclosure sections. Permission diagnostics explicitly describe the current user's permissions.

Use flat dark graphite/slate surfaces, restrained cyan selection and speaking indicators, consistent outline icons, readable labels and subtle pane separators. Preserve installed theme/font preferences, keyboard operation, existing admin tools and the earlier bounded channel editor.

At smaller desktop widths member details overlay the workspace. Below 720px the channel tree becomes a toggleable drawer, the participant strip can scroll horizontally and the voice toolbar wraps. Chat and Files must remain mutually exclusive. Voice, chat, permissions and counts come from live state, without invented capabilities or sample data in production.

Verification covers membership changes, member actions, microphone/deafen state, Files visibility, keyboard focus, compact/zen modes and existing workflows. Browser visual review includes desktop and 640×480 windows. Deliver a rebuilt Windows client.
